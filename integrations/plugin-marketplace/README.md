# Plugin Marketplace (Claude Code / VS Code)

The Agency ships a Claude-format **plugin marketplace**: a
`.claude-plugin/marketplace.json` registry at the repo root that publishes each
division folder as an installable agent plugin. Claude Code, VS Code (Agent
Plugins, Preview), and GitHub Copilot CLI all read this format directly — no
build step, no conversion, and the source agent `.md` files are referenced in
place, never copied or duplicated.

Each division becomes one plugin (`agency-<division>`, e.g. `agency-engineering`,
`agency-finance`) whose `agents` list points at that division's existing agent
files. Add the marketplace once, then install the divisions you need.

## Install

### Claude Code

In a Claude Code session:

```text
/plugin marketplace add msitarzewski/agency-agents
/plugin install agency-engineering@agency-agents
/reload-plugins
```

Or non-interactively from a terminal:

```bash
claude plugin marketplace add msitarzewski/agency-agents
claude plugin install agency-engineering@agency-agents        # default scope: user
claude plugin install agency-engineering@agency-agents --scope project
```

Installed agents appear in the @-mention typeahead scoped by plugin, e.g.
`agency-engineering:frontend-developer`.

> `owner/repo` shorthand clones over SSH by default. Prefer HTTPS with
> `CLAUDE_CODE_PLUGIN_PREFER_HTTPS=1`.

### VS Code (Agent Plugins, Preview)

Add the marketplace to your `settings.json`:

```json
{
  "chat.plugins.enabled": true,
  "chat.plugins.marketplaces": ["msitarzewski/agency-agents"]
}
```

Then open the **Extensions** view (`Ctrl+Shift+X`), search `@agentPlugins`,
accept the marketplace trust prompt on first install, and install the divisions
you want from the **Agent Plugins** list.

### GitHub Copilot CLI

Plugins installed via the GitHub Copilot CLI's plugin marketplace flow are
shared with VS Code automatically. See the [GitHub Copilot CLI plugin
reference](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-plugin-reference)
for the marketplace command.

## Updates

Claude Code re-pulls the marketplace and treats every commit as a new plugin
version (the manifests deliberately omit a `version` field, so the git commit
SHA is used). VS Code checks for updates automatically and on
**Extensions: Check for Extension Updates**. No manual step.

## For maintainers

The manifests are **generated by script but committed** — installs clone the
repo and run nothing, so a gitignored manifest would mean a broken plugin for
every consumer.

Regenerate after adding or renaming an agent or division:

```bash
python3 scripts/build-marketplace.py
```

This rewrites `.claude-plugin/marketplace.json` and every
`<division>/.claude-plugin/plugin.json` from `divisions.json` and the on-disk
frontmatter agent files. CI runs `scripts/check-plugin-marketplace.sh` (plus
`claude plugin validate .`) on every PR and fails the build on drift, so a
missing manifest cannot slip through.
